# Java BMI Calculator

## Description
A simple Java program that calculates a user's Body Mass Index (BMI) based on their weight in pounds and height in meters.

## Features
- Accepts user input using the Scanner class
- Converts weight from pounds to kilograms
- Calculates BMI using the standard formula
- Displays the BMI result and a weight category

## Technologies
- Java
- Scanner class for user input
- If-else statements for BMI classification

## How to Run
1. Open the project in your Java IDE.
2. Run the `BMICalculator.java` file.
3. Enter your weight in pounds.
4. Enter your height in meters.
5. View your BMI result and weight category.

## Formula
BMI = Weight (kg) / Height (m)²
